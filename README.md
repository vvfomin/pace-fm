# pace-fm
Interactive, AI-assisted Policy-Aligned Curriculum Enablement Framework Model. Based on ITCoS FM - The Framework Model of the Innovative Teaching Conceot of Standardisation. The original ITCoS FM was published in 2025 in the proceeddings of The 29th EURAS Conference:

Fomin, V. V., Abdelkafi, N., Blind, K., & Laužikas, R. (2025). The Framework Model for the Promotion of Education about Standardisation in Line with EU Values and Interests. In K. Jakobs (Ed.), The 29th EURAS Conference. Aachener Beiträge zur Informatik.

This project builds on the results of EDU4Standards.eu project.
